# 🎵 AI 五音情境疗愈 APP

> 基于中医五音疗法理论的移动端 AI 疗愈应用，专为老年人情绪调节设计

## 📖 项目简介

AI 五音情境疗愈 APP 是一款结合传统中医五音疗法与现代 AI 技术的移动端应用，通过个性化的疗愈音乐场景，帮助 55 岁以上老年人缓解焦虑、抑郁等负性情绪，提升心理健康水平。

## 🎯 核心特色

- **五音疗愈理论**：基于中医"角、徵、宫、商、羽"五音对应五行脏腑的情绪调节体系
- **AI 个性化推荐**：根据用户情绪状态智能推荐最适合的疗愈场景
- **适老化设计**：大字体（18pt）、大按钮（≥60px）、高对比度，一屏显示无需滑动
- **沉浸式体验**：虚拟疗愈伙伴"小五" + 竹林自然场景 + 360°全景视角

## 🎼 五音映射体系

| 音调 | 五行 | 脏腑 | 情绪调节 | 场景主题 |
|------|------|------|----------|----------|
| 角音 | 木 | 肝胆 | 舒展、生发 | 翠竹林 |
| 徵音 | 火 | 心小肠 | 温暖、喜悦 | 阳光草地 |
| 宫音 | 土 | 脾胃 | 安定、舒缓 | 田园麦田 |
| 商音 | 金 | 肺肠 | 宣泄、净化 | 秋日晴空 |
| 羽音 | 水 | 肾膀胱 | 宁静、沉淀 | 宁静湖面 |

## 📱 四大核心页面

1. **首页** — 虚拟形象"小五" + 竹林背景 + 语音对话入口
2. **疗愈页** — 360° 沉浸式场景 + 语音记录感受
3. **档案页** — 国风水墨风格 + 莫兰迪国风色数据可视化
4. **我的页** — 个人资料管理 + 疗愈历史

## 🚀 快速开始

### 本地预览
```bash
node server.js
```
然后浏览器打开 http://localhost:3001

### 移动端预览
手机和电脑连接同一 WiFi，用手机浏览器访问电脑 IP:3001

## 📌 开发规范

- 遵循适老化设计原则：大字体、大按钮、高对比度
- 单页迭代：一次只修改一个页面，基于反馈逐步完善
- 虚拟形象"小五"与背景为整图集成，不可分离
- 首页背景采用自然竹林风格，不使用遮罩覆盖
