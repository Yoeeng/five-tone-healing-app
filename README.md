# 🎵 AI 五音情境疗愈 APP

> 基于中医五音疗法理论的移动端 AI 疗愈应用，专为老年人情绪调节设计

## 📖 项目简介

AI 五音情境疗愈 APP 是一款结合传统中医五音疗法与现代 AI 技术的移动端应用，通过个性化的疗愈音乐场景，帮助 55 岁以上老年人缓解焦虑、抑郁等负性情绪，提升心理健康水平。

## 🎯 核心特色

- **五音疗愈理论**：基于中医"角、徵、宫、商、羽"五音对应五行脏腑的情绪调节体系
- **AI 个性化推荐**：根据用户情绪状态智能推荐最适合的疗愈场景
- **适老化设计**：大字体（18pt）、大按钮（≥60px）、高对比度，一屏显示无需滑动
- **沉浸式体验**：虚拟疗愈伙伴"小五" + 竹林自然场景 + 360°全景视角

## 🎼 五音映射体系

| 音调 | 五行 | 脏腑 | 情绪调节 | 场景主题 |
|------|------|------|----------|----------|
| 角音 | 木 | 肝胆 | 舒展、生发 | 翠竹林 |
| 徵音 | 火 | 心小肠 | 温暖、喜悦 | 阳光草地 |
| 宫音 | 土 | 脾胃 | 安定、舒缓 | 田园麦田 |
| 商音 | 金 | 肺肠 | 宣泄、净化 | 秋日晴空 |
| 羽音 | 水 | 肾膀胱 | 宁静、沉淀 | 宁静湖面 |

## 📱 四大核心页面

1. **首页** — 虚拟形象"小五" + 竹林背景 + 语音对话入口
2. **疗愈页** — 360° 沉浸式场景 + 语音记录感受
3. **档案页** — 国风水墨风格 + 莫兰迪国风色数据可视化
4. **我的页** — 个人资料管理 + 疗愈历史

## 🚀 快速开始

### 1. 安装依赖
```bash
npm install
```

### 2. 启动服务器
```bash
node server.js
```
服务器会监听 `http://localhost:8080/`，同时提供：
- `GET /*` — 静态文件
- `GET /health` — 健康检查
- `POST /tts` — 云语音 TTS 代理（DashScope CosyVoice）

### 3. 设置 API Key
首次打开 APP，进入「我的」→「AI 密钥设置」，填入 DashScope sk- 开头的 API Key（与 AI 聊天共用）。

### 4. 移动端预览
- 方式一（同一 WiFi）：手机访问 `电脑IP:8080`
- 方式二（任意网络）：本机运行 `cloudflared tunnel --url http://localhost:8080`，把临时域名发给手机访问

## 🎙️ 云语音 TTS 代理说明

`POST /tts` 接收以下 JSON 参数：

| 字段 | 必填 | 说明 |
|------|------|------|
| `apiKey`  | 是 | DashScope API Key（sk- 开头） |
| `text`    | 是 | 要合成的文字 |
| `voice`   | 否 | 音色 ID（默认按 language+gender 自动选） |
| `language`| 否 | mandarin / cantonese（默认 mandarin） |
| `gender`  | 否 | female / male（默认 female） |
| `rate`    | 否 | 语速（默认 1.0） |

成功返回 `audio/mpeg` 二进制；失败返回 `{"error": "..."}` JSON。

## 📌 开发规范

- 遵循适老化设计原则：大字体、大按钮、高对比度
- 单页迭代：一次只修改一个页面，基于反馈逐步完善
- 虚拟形象"小五"与背景为整图集成，不可分离
- 首页背景采用自然竹林风格，不使用遮罩覆盖
